### Марковская модель погоды

**Задание:**  
Смоделировать погоду по дням:

- 1 — ясно  
- 2 — облачно  
- 3 — пасмурно  

Единица времени — **1 день**.  
Задать интенсивности переходов между состояниями.

**Требования:**
1. Выполнить моделирование в «реальном» времени с визуализацией.
2. Провести статистическую обработку результатов.
3. Сравнить эмпирическое распределение с теоретическим стационарным.

## Реализация:

Матрица интенсивностей переходов:

```
        →ясно  →обл  →пасм
ясно   [ -0.4   0.3   0.1 ]
обл    [  0.4  -0.8   0.4 ]
пасм   [  0.1   0.4  -0.5 ]
```

| Элемент | Роль |
|---|---|
| `q_ij`, `j ≠ i` | Интенсивность перехода `i → j` — сколько раз в день процесс уходит из `i` в `j` |
| `q_i = Σ_{j≠i} q_ij` | Суммарная интенсивность выхода из состояния `i` |
| `q_ii = −q_i` | Диагональ, из-за неё сумма каждой строки равна нулю |
| `1/q_i` | Среднее время пребывания в состоянии |


### Алгоритм моделирования

На каждом шаге делается два розыгрыша: **сколько времени процесс просидит** в текущем состоянии и **куда он потом уйдёт**.

```python
def next_event(i):
    alpha = base_random()
    tau = math.log(alpha) / Q[i][i]        # сколько ещё сидим в состоянии i
    j = generate_dsv(transition_probs(i))  # куда уйдём
    return tau, j
```

Сама дискретная случайная величина разыгрывается методом обратной функции — отрезок (0;1) режется на куски длиной `p_j`, и смотрим, в какой кусок попал `alpha`:

```python
def generate_dsv(probs):
    alpha = base_random()
    accumulated = 0.0
    for j in range(len(probs)):
        accumulated += probs[j]
        if alpha < accumulated:
            return j
    return len(probs) - 1
```

## Теоретические значения

Стационарное распределение:

```python
def stationary_theory():
    A = np.array(Q, dtype=float).T      # pi*Q = 0  <=>  Q^T * pi^T = 0
    A = np.vstack([A, np.ones(N)])      # дописываем условие нормировки
    b = np.zeros(N + 1); b[-1] = 1.0
    pi, _, _, _ = np.linalg.lstsq(A, b, rcond=None)
    return list(pi)
```

## Вывод

Реализовано имитационное моделирование смены погоды как цепи Маркова с непрерывным временем:

- время пребывания в состоянии разыгрывается по формуле `tau = ln(alpha)/q_ii`, следующее состояние — как дискретная случайная величина с рядом распределения `−q_ij/q_ii`;
- статистическая обработка выполнена по времени пребывания в состояниях, результат выводится таблицей и гистограммой;
- эмпирическая оценка совпала с точным теоретическим решением `pi = (24/63, 19/63, 20/63)` до третьего знака.

Отклонения от теоретических значений объясняются конечной длительностью моделирования — следствие закона больших чисел. При увеличении модельного времени эмпирическая оценка сходится к теоретической, что видно прямо в процессе работы программы: столбики на гистограмме постепенно выравниваются.
