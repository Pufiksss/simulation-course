### Пуассоновский поток. События на сервере

Моделирование потока заявок на сервер.

**Задание:**
- событие — поступление заявки;
- определить число заявок за интервал времени T;
- построить распределение числа заявок;
- вычислить среднее и дисперсию;
- сделать вывод.

---

## Реализация — простейший поток событий

Простейший (стационарный пуассоновский) поток задаётся тремя свойствами:

| Свойство | Что означает для сервера |
|---|---|
| Стационарность | Число заявок зависит только от длины интервала, а не от того, когда он начался |
| Ординарность | Две заявки не приходят строго в один и тот же момент |
| Отсутствие последействия | Заявки поступают независимо друг от друга |

Единственный параметр модели — **интенсивность потока λ**, среднее число заявок в единицу времени.

Взятые параметры:

| Параметр | Значение | Роль |
|---|---|---|
| `λ` | 2.0 заявок/сек | Интенсивность потока |
| `T` | 10 сек | Длина интервала наблюдения |
| `N` | 10 000 | Число независимых прогонов |
| `λ·T` | 20 | Ожидаемое число заявок за интервал |

### Ключевое свойство: интервалы между заявками

Длины интервалов между соседними заявками в простейшем потоке распределены **экспоненциально** с параметром λ. Разыгрываем интервал методом обратной функции:

```python
def next_interval(lam):
    alpha = base_random()
    return -math.log(alpha) / lam
```

### Моделирование потока

Начинаем с нулевого момента и каждый раз прибавляем очередной интервал:

```python
def simulate_flow(lam, interval):
    moments = []
    t = 0.0
    while True:
        t = t + next_interval(lam)
        if t > interval:
            break
        moments.append(t)
    return moments
```

Как только очередной момент вылезает за границу `T`, останавливаемся. Длина списка — число заявок за интервал.

### Статистическая обработка

Делаем `N` независимых прогонов длиной `T` и запоминаем число заявок в каждом:

```python
def run_experiment(lam, interval, runs):
    counts = []
    k = 0
    while k < runs:
        counts.append(count_events(lam, interval))
        k = k + 1
    return counts
```

Эмпирическое распределение — доля прогонов, в которых пришло ровно `m` заявок:

```python
def empirical_distribution(counts):
    top = max(counts)
    freq = [0] * (top + 1)
    for c in counts:
        freq[c] = freq[c] + 1
    return [f / len(counts) for f in freq]
```

Среднее и дисперсия считаются напрямую по определению:

```python
def sample_mean(values):
    return sum(values) / len(values)

def sample_variance(values):
    m = sample_mean(values)
    return sum((v - m) ** 2 for v in values) / len(values)
```

## Теоретические значения

Число заявок за интервал длины `T` распределено **по закону Пуассона** с параметром `a = λ·T`

```python
def poisson_probs(a, top):
    probs = [math.exp(-a)]              
    for m in range(1, top + 1):
        probs.append(probs[m - 1] * a / m) 
    return probs
```

Особенность распределения Пуассона: **среднее и дисперсия совпадают** и равны `a`.

```
M[X] = λ·T = 2.0 · 10 = 20
D[X] = λ·T = 2.0 · 10 = 20
D[X] / M[X] = 1
```

## Результаты (λ = 2.0, T = 10 сек, N = 10 000 прогонов)

| Характеристика | Эмпирика | Теория | Ошибка |
|---|---|---|---|
| Среднее число заявок | 20.0239 | 20.0000 | 0.0239 |
| Дисперсия числа заявок | 19.8661 | 20.0000 | 0.1339 |
| Отношение дисперсии к среднему | 0.9921 | 1.0000 | 0.0079 |

## Вывод

Реализовано моделирование потока запросов на сервер как простейшего пуассоновского потока:

- поток строится последовательным розыгрышем интервалов по формуле `tau = −ln(alpha)/λ`, момент следующей заявки получается как `t_{i+1} = t_i + tau`;
- за интервал `T = 10` секунд при интенсивности `λ = 2` заявки в секунду приходит в среднем 20 заявок, что совпадает с теоретическим `λ·T`;
- эмпирическое распределение числа заявок совпало с теоретическим распределением Пуассона `P{X = m} = (λT)^m/m! · e^(−λT)`;
- выборочное среднее (20.0239) и выборочная дисперсия (19.8661) практически равны между собой и равны `λ·T = 20`, что является **характерным признаком пуассоновского потока** — у него математическое ожидание и дисперсия совпадают;
- отношение дисперсии к среднему получилось 0.9921 при теоретической единице.
