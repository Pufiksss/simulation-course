### Имитационное моделирование дискретных и непрерывных случайных величин

**Задание:**
- реализовать генерацию дискретной случайной величины, заданной рядом распределения:
  - вычислить эмпирические вероятности;
  - вычислить выборочные среднее и дисперсию, их относительные погрешности;
  - вычислить статистику χ² и применить критерий χ² при N = 10, 100, 1 000, 10 000;
- реализовать генератор нормальной случайной величины:
  - построить гистограммы;
  - сравнить точность моделирования при разных объёмах выборки;
- сделать вывод.

---

## Реализация

### Часть 1. Дискретная случайная величина

Заданный ряд распределения:

| Значение | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| Вероятность | 0.1 | 0.2 | 0.4 | 0.2 | 0.1 |

Генерация **методом обратной функции**: отрезок (0;1) режется на куски длиной `p_1, ..., p_m`. Куда попало `alpha` — такое значение и выпало.

```python
def generate_dsv(probs):
    alpha = base_random()
    accumulated = 0.0
    for j in range(len(probs)):
        accumulated += probs[j]
        if alpha < accumulated:
            return j
    return len(probs) - 1
```


**Теоретические значения:**

```
M[X] = Σ x_i · p_i = 1·0.1 + 2·0.2 + 3·0.4 + 4·0.2 + 5·0.1 = 3.0
D[X] = Σ x_i²·p_i − M[X]² = 10.2 − 9.0 = 1.2
```

### Часть 2. Нормальная случайная величина

**Метод суммирования**:

```python
def normal_sum12(a, sigma):
    total = 0.0
    for _ in range(12):
        total += base_random()
    return a + sigma * (total - 6.0)
```

### Статистическая обработка

Выборочные среднее и дисперсия считаются по определению:

```python
def sample_mean(values):
    return sum(values) / len(values)         

def sample_variance(values):
    m = sample_mean(values)                  
    return sum(v * v for v in values) / len(values) - m * m
```

Относительная погрешность — в процентах от теоретического значения:

```python
def relative_error(empirical, theoretical):
    return abs(empirical - theoretical) / abs(theoretical) * 100.0
```

**Критерий согласия хи-квадрат:**

Для дискретной величины `p_i` берутся прямо из ряда распределения, число степеней свободы `m − 1 = 4`, критическое значение при уровне значимости 0.05 равно 9.488.

Для непрерывной величины теоретическая вероятность попасть в интервал считается через функцию распределения:

```
p_i = F(b_i) − F(a_i)
```

Функция распределения нормальной СВ выражается через функцию ошибок:

```python
def normal_cdf(x, a, sigma):
    return 0.5 * (1.0 + math.erf((x - a) / (sigma * math.sqrt(2.0))))
```

**Число интервалов** выбирается по формуле Стёрджеса:

```python
def sturges(size):
    return int(math.ceil(math.log(size, 2))) + 1
```

Даёт 5, 8, 11 и 15 интервалов для N = 10, 100, 1000 и 10000.

**Правило применимости критерия.** В каждом интервале ожидаемое число значений `N·p_i` должно быть не меньше пяти. Крайние интервалы, где это не выполняется, объединяются с соседними, и число степеней свободы уменьшается:

```python
def merge_small_bins(probs, counts, size, minimum=5.0):
    p, c = list(probs), list(counts)
    while len(p) > 2 and size * p[0] < minimum:
        p[1] += p[0]; c[1] += c[0]; p.pop(0); c.pop(0)
    while len(p) > 2 and size * p[-1] < minimum:
        p[-2] += p[-1]; c[-2] += c[-1]; p.pop(); c.pop()
    return p, c
```

При N = 10 из пяти интервалов остаётся 2, при N = 100 из восьми — 4, при N = 1000 из одиннадцати — 9, при N = 10000 из пятнадцати — 13.
